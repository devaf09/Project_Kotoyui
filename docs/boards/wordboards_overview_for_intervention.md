## 2. 光の器（board_light.BatchDevice）

- 1 次元、画素 n = 2,048、板 4 枚（8 枚とほぼ同じ精度で計算は半分）。入口は 1 つ、出口の周波数 8.. が属性。明るさ = 属性の割合、余りは暗い出口へ。
- v1: 板の位相を画素ごと（重み 8,192 / 語）、乱数から 600 回。
- v1f: 板の位相を低い周波数成分 512 個（重み 4,096 / 語）、設計（往復で振幅を直す Gerchberg–Saxton）の位相を初めの板にして 300 回。
- 画素 n が属性の数の上限を決める。板を増やしても属性は増えない。周波数成分で持っても、必要な重みは「属性 1 つに約 2」で、属性の数に比例する。

## 4. 介入の研究で使うときの要点

- 融合・消去・差分は「明るさの足し引き」でやる。器（板）どうしを混ぜると壊れる。和は順番によらないので、親を木の形で積める。
- 親の器が要るときは、子の器からではなく親の割合から設計して少し学ぶ。
- 崩した文の見分けは 0.79 で、光の器は情報を落としていない。上げるのは属性の取り方（語板の中身）の仕事。
- 気をつける点: D のクラスは WordNet の語義をすべて数えるので、「トム → uncle_tom」のような外れが混じる（v2 で文から語義を絞る予定）。語板は頻度 5 以上の語だけ。

### 介入の研究で使うときの要点（v2）
- **文脈 = 前後の文の語板の光の和**。介入（足す・消す）と同じ操作で文脈が作れ、文脈との重なりで的はずれな語・文が分かる（いちばん合わない語を G の重なりで選ぶと 0.63）。
- 帯 G の読み方: 語板の「話題:クラス」は、その語がどんな話の中に出るか。介入で語を差し替えるときの「話の流れに合うか」の物差しに使える。
