# 品詞語板・機能語語板 第 1 版（辞書の属性だけ、2026-11-05）

コード: リポジトリの `lexicon/special_boards.py`（属性の表）、`lexicon/board_light.py`（光の器で学ぶ・確かめる）。
データ: このフォルダの `pos_boards.json`・`func_boards.json`（属性の表）、`light_results_s*.json`・`light_bright_s*.npz`（3 seed の結果と学んだ明るさ）。

## 作った語板

- **品詞語板 36 枚**: UniDic の品詞（名詞-普通名詞、動詞-一般、助詞-格助詞 …）ごとに 1 枚。
  属性 7 観点 42 値: 自立/付属、活用する/しない、活用型のまとまり（五段・一段・サ変・形容詞・助動詞・文語…）、活用形、語種（和・漢・外・混・固）、書字、長さ。
- **機能語語板 502 枚**: 形式名詞 119、補助動詞 116、助動詞 64、指示詞 36、副助詞 36、終助詞 34、接続詞 31、接続助詞 22、フィラー 13、補助形容詞 12、格助詞 12、係助詞 6、準体助詞 1。
  属性 9 観点 111 値: 品詞、機能（格・主題・取り立て・接続・終助・コピュラ・テンス・アスペクト・ヴォイス・否定・丁寧・願望・推量・伝聞・授受・尊敬…）、
  意味（が = 主格、を = 対格 など主な助詞 23 個は手の表）、指示詞の距離（近・中・遠・不定）と系列（もの・連体・場所・方向・様子・人）、活用型、活用形、文語か、長さ。
  同じ形でも品詞が違えば別の語板（から = 格助詞 / 接続助詞）。補助動詞は読みで 1 枚にまとめた（仕舞う / しまう）。

## 読み方

- **光を重ねる融合（和）は劣化しない**。親の語板を別に学ばなくてよい（I10 と同じ）。
- **器そのものを融合する（位相の板を平均する）と、ほぼ壊れる**（差 0.7〜0.9、光の量も 2〜5 割に落ちる）。板の位相は子ごとにばらばらに学ばれていて、平均すると回折の道筋が打ち消し合う。
  持ち主の「融合（劣化あり）」を器の上でやるには、子を同じ初めの板から少しだけ学ばせる、または共通の板 + 子ごとの差分の板に分ける、といった形が要りそう（次の一手）。
- 消去と差分は、属性が辞書の手のラベルなので易しい（差分 100%）。本当の試しは、文から属性を学ぶ第 2 版で。
- **逆回しで語板そのものを当てにくい**（品詞だけなら 0.04）のは、辞書の属性だけでは同じ品詞の機能語どうしが区別できないため。
  語を見分けるのは「前に付く語の品詞・活用形」「係り方」「よく一緒に出る語」で、これは UD Japanese-GSD や Tatoeba の文から取る（第 2 版）。

## 限界

- 機能と意味は手の表（助動詞約 60・補助動詞約 30・助詞約 23）。補助動詞の 100 個は機能が「その他」のまま。
- 形式名詞・補助動詞の一部は IPAdic の「非自立」から取ったので、ほかの辞書と区切りが少し違う。
- 学ぶ正解は辞書から数えた割合そのもので、文から学んではいない（デジタルの数え上げ）。
