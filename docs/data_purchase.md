# 会話データを買う・申し込む方法（調べた結果、2026-10-25）

持ち主の依頼（2026-10-25）: 会話データを購入できる方法と、そのライセンスを調べてまとめる。
各ページを 2026-10-25 に読んだもの（法律の判断ではない。値段・条件は申し込む前に提供元に確かめる）。

## 結論（先に）

- **いますぐ買わなくてよい。** 無料で取ったデータ（青空文庫 4,477 作品・RealPersonaChat・名大会話コーパス）で、データを増やすと効くか（規模の線）を先に見る。
- 買うなら **国語研の『日本語日常会話コーパス』（CEJC）の有償版「一般」（25 万円、税別）** が一番合う。現代の日常会話で、書き起こしつき。
  ただし「教育研究機関以外の所属」向けの区分で、**所属のない個人が申し込めるかはページに書いていない**。買う前に国語研に問い合わせる必要がある。
- 無料で申し込めるものに **NII の「ニコニコデータセット」**（コメント約 41 億件、研究目的なら誰でも）がある。会話ではないが、くだけた短い言い回しが大量にある。
- どの有償データも共通して、**データの再配布・データを組み込んだプログラムや学習したモデルの公開を禁じるか、制限する**。学習した重みを当面公開しない方針（D4）とは合う。

## 勧め（★）と順番

1. **いまは買わない**。無料のデータで見積もりを測り直し（実行中）、データを増やすと隠し味・口調の当たりが伸びるかを見る。伸びるなら、データを買う価値がある。
2. 伸びると分かったら、**CEJC 有償版「一般」に、所属のない個人として申し込めるかを国語研に問い合わせる**（問い合わせは持ち主から。送るのは外への連絡なので、こちらからは送らない）。
3. くだけた言い回しを増やしたいときは、**ニコニコデータセットを申し込む**（無料、研究目的）。会話ではないので、2DWIG の口調・2DTG の言い回しの学習に限って使う。外部の生成 AI に入れない・学習したモデルを公開しない、を守る。
4. GSK のタグ（44,000 円）は、意図の理解（M4）の段階で、対話行為のラベルが要ると分かってから検討する。

## 買ったデータの置き場と約束（買うときの案）

- 置き場は data/ の下（git の対象外）。ライセンスごとに data/licensed/<名前>/ に分ける（data_wild/ には置かない。条件のはっきりしたデータなので）。
- data/MANIFEST.json に、契約の種類・期間・利用者・禁止事項の要点を書く。
- 契約の禁止事項（再配布・プログラムやモデルの公開・外部の生成 AI への入力）を NOTES.md の「データ」の節に書き、そのデータで学習した結果は名前で分ける。
- このリポジトリを公開するときは、そのデータで作った例・図・重みを入れない。
