# 作ってもらう会話の形（持ち主が別の AI に頼む時の頼み方。2026-11-28）

持ち主の案: 状況を決めて、別の AI に 100 行くらいの会話をいくつか作ってもらう（Gemini の大きめの物、持ち主のサーバの GPU で動かす物、ChatGPT の 3 通り）。
持ち主: 「外部公開OKなAIで作ってもらおうかと思ってるから、別に公開してもOKだよ。」→ 作ってもらった会話は、リポジトリに置いてよい。

## 何に使うか

今の材料には「答え」の印が無くて確かめられない所の、答え合わせに使う。主な材料にはしない（AI が作る会話は、主語を言いすぎ、話がきれいにつながりすぎる事が多い）。

1. 言われなかった主語は、話し手か、相手か、別の人か（疑問の物差し、84-2 節。追記 18）。
2. 場面の切れ目（切れ目の信号、84-1 節。追記 17）。
3. 同じ場面の話が幾つも有る時に、場面を保てるか（テーマ波、84-3 節）。

## 頼む時の文（そのまま貼れる形）

```
次の形で、日本語の会話を作ってください。

- 状況: （ここに状況。例: 雨の日の放課後、二人が教室に残っている）
- 話し手は A と B の 2 人。1 行に 1 発言。全部で 100 行くらい。
- 会話の途中で、場面（場所や、している事）が 2〜3 回替わるようにしてください。替わる行の前に、
  「#場面 2: （短い説明）」のような行を入れてください。初めは「#場面 1: …」。
- 主語（だれが）を言わない発言を、半分以上にしてください。日本語の普段の会話のように。
- 各発言の後ろに、タブで区切って、その発言の「だれが」を書いてください。
  書き方: A（話し手 A 自身）／B（話し手 B 自身）／AB（2 人とも）／その他:（人や物の名前。例 その他:猫）／なし（主語の無い発言。あいさつなど）
  言っていても、言っていなくても、全部の行に書いてください。
- 主語を言った行は、行の終わりに、タブで区切って「言った」と書いてください。言わなかった行は「言わない」。
- 説明や前置きは書かずに、会話だけを出してください。

形の例:
#場面 1: 放課後の教室
A: 雨、やまないね。	なし	言わない
B: 傘、忘れちゃった。	B	言わない
A: 私の、折りたたみなら有るよ。	A	言った
```

## 受け取った後

- 1 つの会話を 1 つのファイルにする。ファイル名に、作った AI の種類と番号を入れる（例 `gemini_01.txt`、`gpt_01.txt`、`local_01.txt`）。
  作った AI ごとに癖が違うので、数える時も AI ごとに分けて見る。
- 置き場所は、持ち主が決める（リポジトリに置いてよい、と持ち主）。
- 印の付け方が崩れている行（タブが無い、だれが の欄が無い）は、数える道具の方で数えて、捨てた数を記録に出す。
- 使う前に、各サービスの決まり（作った物の使い方）を、持ち主が確かめる。
