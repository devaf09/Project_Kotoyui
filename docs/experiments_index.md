## 4. いいとこ取りの形（案、未確定）

持ち主の言葉:「一度いいとこどりをした仕組みを一度作ってみてもいいかも。」

今の数えから、組み合わせる順の案。

1. 聞いた組そのものが有る問いは、関係の表で答える（I49s: 表が一番強い所）。
2. 表が片方の語や似た語に頼る問い、答えられない問いは、波で解く形（属性・席あり）で答える（I49s: 解く形が勝つ所）。
3. 解く形の 1 位と並ぶ候補が有る時は、この話でもう出た語、次に席ごとの薄れる板、の順で決め手にする（I49u・I49z）。 ← きれいな材料では効かず、下がる（I49zt、2026-11-24）。「だれが」の席だけなら残る。
4. 採点は、正しい物と、正しいと言える物の両方で出す（I49w）。

組んで数えた結果（I49zb、[i49_inner_vessel.md](i49_inner_vessel.md) 30 節）: 1 と 2 だけで .445 / .465（表だけは .432 / .453）。3 まで入れて .451 / .465。正しいと言える物も合わせると .609 / .627。

表に任せる段を手で置かず、段ごとの当たりを数えて選ぶ形（I49zc、`Mix(upper=None)`）でも .444 / .464。手で置く値は「同じ数なら表」だけ。こちらを土台にする。
