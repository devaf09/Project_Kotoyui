# docs/samples/ — 会話の例（持ち主が読んで判断するためのもの）

実験で作った文・返事を、条件ごとに並べて置く。ファイル名は `mN_内容.md`（例: m1_flavor.md）。
各ファイルの冒頭に、作った条件（実験の番号・グレインの組み合わせ・seed）と、自動の指標（繰り返し率など）を書く。
手で選んだ「良い例」だけにせず、決まった手順で選んだ例（先頭から N 件、または乱数で N 件）を並べる。

現代の雑談のデータ（RealPersonaChat・名大会話コーパス）で学んだモデルが作った文の例（m1_est_modern_style・m1_exp02_*・m1_exp03_*）は、データの文と重なる所があるため、非公開の置き場 ../Project_Kotoyui_private/docs/samples/ に移した（2026-11-03 持ち主の依頼）。ここに残すのは青空文庫（著作権切れ）で作った例だけ。
