# I48: 意味の波を、すくった後も周波数のまま持つ板（説明シート）

2026-11-13。道具は `intervention/i48_wave_board.py`。I47（[i47_wave_resonance.md](i47_wave_resonance.md)）で分かった形を、次の道具として作り直した。

## 1. 方針（持ち主）

- 可能な限り周波数成分のまま持つ。周波数から展開する手間は気にせず、容量と精度を優先する。
- 層を後から増やせる形にする。
- GPU 2 台に層ごとに分ける。進み具合はログに出す。
- 追加学習は「昼」と「夜」の 2 つに分ける（2026-11-14）。
  - 昼（会話中）: 今の語の波のまま、新しい場面を板の末尾に足すだけ。知らない語には乱数の印をその場で割り当てる。足した場面は短期の置き場に分けて持つ。
  - 夜（まとめて）: その日の行も含めて語の波を学び直し、全部の層を作り直して、短期の置き場を本体に合流させる。決まった試しで当たり・向きを測り、下がっていたら前の日の板に戻す。

## 2. 作り

| 物 | 持ち方 |
|---|---|
| 語の波（共鳴の鍵） | 流れから学んだ位相（I47a と同じ学び方） |
| 語の印（読み出し用） | 語ごとの乱数の位相。ほかの語と重ならないので、混信はただの雑音になる |
| 場面の波 | 層ごとに、窓（前の 1・3・10・30 行…）の語の波の重ね合わせ |
| 次の行の波 | 次の行の語の印の重ね合わせ |
| すくった板 | 共鳴の強い 30 場面の「次の行の波」を、共鳴の強さの 2 乗で重ねた 1 本の波。層の間もこの波で渡す |

- **語に戻すのは最後だけ**: 波と語の印の内積を取る（読み出し）。
- **雑音の床**: 波に居ない語の読みは、平均 0・ばらつき σ = |波| ÷ (D√2) の雑音になる。読み出す語が V 個の時、雑音だけで出るいちばん大きい読みの見込み σ√(2 ln V) より下を消す。手で置く値ではなく、波の強さ・長さ・語の数から決まる。D が大きいほど床が下がり、弱い語まで読める。
- **そろえる**は 2 つの形を比べる。
  - 読み出してそろえる: 層ごとに読み出し、I47b と同じそろえ方をして、語の印で波に重ね直す。
  - 周波数ごとにそろえる: 波の枠ごとの大きさで同じそろえ方をする。層の間で語に戻さない。
- **層を足す**: `WaveBoard.add_layer(100)` か `--wins 1,3,10,30,100`。場面は (作品, 行) で持つので、しまってある行から新しい窓の波を作る。
- **置き場**: `--devices cuda:0,cuda:1` で層を順に GPU に割り当て、層ごとに同時に共鳴させる。載り切らない分は PC のメモリから区切りごとに流す（共有メモリにあふれさせない）。問いは 256 個ずつまとめる。使い終わった GPU のメモリは空ける。
- **数の持ち方**（`--store`）: c128（1 枠 16 バイト）、c64（8）、p8（語の波と印は位相だけ 8 ビット = 1、場面の波は半精度の実部・虚部 = 4）。計算に使う瞬間だけ complex64 に戻す。
- **ログ**: `--log` に、学び・層づくり・測りの進みと残り時間、GPU の使用量を書く。

I47b の道具（`i47b_layers_negation.py`）と同じ分け方で、表の板は同じ数になる（4 層そろえる 当たり 0.261・中身 0.063、1 層 0.195・0.039）。

分かったこと:

- **数の持ち方では変わらない**。c128・c64・位相 8 ビットの差は ±0.002 以内。位相 8 ビットは、語 1 つが c128 の 16 分の 1、場面の波が 4 分の 1。軽くなった分を D に回せる。
- **波の板は D を増やすと表の板に近づく**。表との重なりは D 512 で 7.4 語、4,096 で 9.1 語。D 512 では波から読める語が 12（表は 26）で当たりが 0.017 低い。D 2,048 から上は表と並ぶ（0.263 と 0.260）。
- **周波数ごとにそろえる形は、語に戻さなくても表と並ぶ**（D 512 でも 0.261／0.057）。層の間で読み出さずに済む。
- **重ねるだけで最後に 1 回読む形がいちばん当たる**（D 2,048 で 0.268／0.061）。雑音の床が、ぼやけた所を消す役をしている。表の板で「そろえずに重ねる」と中身が落ちた（0.052）のと違う。
- **向きは、この大きさの資料では D で伸びない**（1 層 0.230 から 0.236）。頭打ちが見えた RealPersonaChat 全部（13,083 対話）で測る必要がある。まだ測っていない。

注意: 試しは 4,613 組。0.005 くらいの差は揺れの中。資料が小さいので、RealPersonaChat で確かめ直す。

## 4. bot の返事作りにつなぐ口

`chat_bot3.py`・`chat_partner.py` に `--wave <会話の資料の解析済み JSON>` を足した（`--wave_D`・`--wave_store`・`--wave_devices`）。

1. 会話のここまでの行（相手と自分）を、層の窓の波にして場面をすくう。
2. 層ごとに読み出してそろえ、重ねてもう一度そろえ、波に重ね直す（返事の意味の波）。
3. すくった場面の「次の行」の波と、返事の意味の波を共鳴させ、強い 12 行を行づくりの場の板に入れる（重みは共鳴の強さ）。
4. 返事の理由（why）に、波から読んだ語を書く。

動くことは確かめた。返事が良くなるかは、話し相手との会話（20 会話 × 12 往復、seed 2 つ）でまだ測っていない。
