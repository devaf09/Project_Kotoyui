# 新しい語板 1 版目の設計メモ（案、未確定。2026-11-19）

持ち主の判断: 語板から作り直す。古い版（今の語板・本体・答え合わせ）は残して、比べる土台にする。
1 版目は「使われ方の波」だけ。状況の波・候補を育てる仕組み・感情の値・迂回は入れない。

## 1. なぜ作り直すか

- 今の語板は「この語にどんな属性があるか」（外の辞書由来のクラス・話題の分類）だけで、「この語がどんな文の流れの中で使われたか」を持っていない。
- 下調べ A: 隠した語の語板の属性を前後から当てても、いつも同じ答えより +.02 しか近くならず、出会いを重ねても伸びない。
- 試し I48ay・az・ba: 鍵・列・と を分ける のどれも、と の人（0/14）を動かさない。全体の波 R1 を抜いても選びは 0.5% しか替わらない。今の選びは、ほぼ数えの表 1 つで決まっている。
- 持ち主: 「語板に使われ方や複数の状況の波が無い。文全体の主語属性→述語属性…という流れの一部でも語が持たないと適合しない」。

## 2. 1 版目の形

### 2.1 使われ方の波（語ごと、種類ごとに別の板）

語 w ごとに、学びの文での使われ方を、種類ごとに別の波として持つ（混ぜない）。

| 種類 | 中身 | 何を数えるか |
|---|---|---|
| 前 | 語の前の間の詰め物 | 詰め物のクラス（今の 300 ＋ その他） |
| 後ろ | 語の後ろの間の詰め物 | 同じ |
| 述語 | 語の右のいちばん近い述語の属性 | 述語の語板の属性（今の語板を最初のパレットとして使う） |
| 位置 | 文の中の位置 | 頭・中・末 |
| 印 | 語のいる節の意味の印 | 過去・否定・丁寧・進行・問い |

- 波は complex64、長さ DK。種類 k の項目 j に、決まった乱数の位相の符号（白い雑音、種で固定）を割り当て、出会うたびにその符号を足す（数えて足すだけ）。
- 種類ごとに別の符号の組を使うので、種類どうしは混ざらない。状況の波（丁寧さ等）は、後から別の種類として足せる口だけを空けておく。

### 2.2 照らし方（ニュートンリングの読み）

- 候補（詰め物 c）を照らす時は、候補の符号と語の波を重ねる。そのうえで、波の長さ DK を B 本の帯に分け、帯ごとの重なり z_b（複素数）を出す。
- 強さ（AM）: |Σ_b z_b|。何回その使われ方をしたか（数えの多さ）に当たる。
- そろい具合（FM）: |Σ_b z_b| / Σ_b |z_b|。帯ごとの位相がそろっていれば 1 に近く、にじみ（たまたまの重なり）なら帯ごとにばらばらで小さい。基準の光（候補の符号）と比べて、どの帯で・どれだけずれているかを段階で読む形（ニュートンリング）。
- 選びへの入れ方（比べる）:
  - (i) FM で探して AM で選ぶ: そろい具合が床を越えた候補だけ残し、強さで並べる。
  - (ii) AM だけ。
  - (iii) 今の本体だけ（差し込みを切る）。
- 床は、混ぜた時（符号を取り替えた時）のそろい具合の分布から決める（手の線なし）。

### 2.3 数えの少ない語

- 使われ方の数えが床（2 ln V、V = 箱の数。D と同じ式）に届かない語は、今の語板の属性（古い版の点）に頼る。新しい波の点は足さない。

### 2.4 差し込みとして持つ

- 本体（i48core.model.Model）は書き換えない。新しい語板は差し込み（extras）。抜けば今の数字に戻る事を、答え合わせ（golden）で確かめる。

## 3. 測り

今の本体と同じ 5 万文・1,000 文で:

- 間・文末・文、助詞ごとの当たりと害、と の人 14 件、言える（物差しは学んでいない文）、筋の無い共振、想定外の反応
- 新しい語板を抜くと替わる選びの数（波が選びを決めているか）
- 隠した語の次の使われ方の当たり（下調べ G と同じ形）

## 4. 手で置く値（最小）

- DK（波の長さ）、B（帯の数）、符号の乱数の種。

## 5. 期限と止め方

- 目安は 2〜3 日。
- と の人・言える・替わる選びの数のどれも動かなければ、そこで止めて報告する。

## 6. 下調べ G の結果（作りに生かす所）

- 隠した語 279（下調べ A と同じ選び方で、9 回目以降の出会いがある語）。学びの文での回数の三分位で、少ない（2 回以下）・中（9 回以下）・多い。
- 次の後ろの詰め物が上位 1 に入る割合（出会い 1 → 2 → 4 → 8 回）:
  - 当てずっぽう（全語の平均）.161
  - (a) 今の語板の属性から .211（出会いの回数に依らない）
  - (b) 使われ方の波から .226 → .251 → .292 → .311
  - (c) 両方 .232 → .271 → .311 → .321
- 述語が上位 20 に入る割合:
  - 当てずっぽう .369、(a) .338（当てずっぽうより下）
  - (b) .271 → .320 → .354 → .359
  - (c) .356 → .375 → .383 → .387
- 頻度の帯ごとでも同じ向き（後ろ上位 1、8 回で: 少ない .304・中 .310・多い .320、語板は .200〜.221）。
- 読み: 使われ方の波は、出会うほど次の使われ方をよく当てる（後ろの詰め物で 1 回 .226 → 8 回 .311）。今の語板の属性は、出会いを重ねても .211 のまま。述語は当てにくいが、両方を合わせると当てずっぽうを少し越える。
- 作りに生かす所: 後ろ・前の詰め物の波を中心にする。述語は、今の語板の属性（パレット）と合わせて使う。
