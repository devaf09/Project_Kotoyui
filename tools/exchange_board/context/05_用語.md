# 用語

| 言葉 | 意味 |
|---|---|
| 板 | 語や行や人ごとに、どこがどれだけ明るいかを持つ物。ベクトルに近い |
| 波 | 板を周波数成分（複素数）で持った物。重ねたり、薄めたり、干渉させたりできる |
| グレイン | 数え上げで学ぶ小さな器。判断を出す |
| 器（内面の器） | 入力が無くても時間が進み、速さの違う波を並べて持つ所 |
| 思考のループ | 読む、考える、話す、待つ を選んで回す所 |
| 光の器 | 光学の共振を模した器（SinWave）。今は計算機の中の模擬 |
| 違和感 | 期待と観測の差。気づきの元 |
| 自覚と介入の環 | 見立て → 試す → 振り返り → 気づき → 反応 の環。この AI の知性 |
| 席 | 「だれが」「何を」「どうした」の 3 つの位置 |
| 3 つ組 | 1 つの文から取った（だれが、何を、どうした） |
| 持った波（Hold） | 席ごとに、聞いた語の波を半減期で薄めながら足した物 |
| 半減期 | 何行で重さが半分になるか |
| 隣の表 | 前の行の語から、次の行の語を引く数えの表 |
| 当てずっぽう | 候補から何も知らずに選んだ時の当たり。数と必ず並べる |
| 読み | 確かめていない見立て |
| 手で置いた値 | しきい値や重みのように、数えではなく人が決めた値 |
| --gate | 危ない相談を見つける所。分類器に替えない |
| run番号 | PC で走らせた試しの番号 |
| I49zzz… | 試しの名前。記録の節と、docs/experiments_index.md で引ける |
