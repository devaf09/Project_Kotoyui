# 残っている問題（2026-11-28）

## 1. 大きな問題

- 話したい事を話せない: 思考のループの骨組みは有るが、話す中身は聞いた語の並べ直しに近い。「何のために話すか」がまだ無い。
- 意味を文脈から決める: 意味を渡せば述語の形は作れるが、意味を文脈から決める所は 32% ほど。
- 2 つを合わせた関係が学べていない: 「だれが・何を」から「どうした」を当てる時、当たりの多くは 1 語の表から来ている。組み合わせの関係はまだ。
- 場面を保てない: 自分で続けた文が、場面をすぐ離れる。動きの語で場面を持つ形は効かなかった（84-3）。物や場所で場面を表す形が次の候補（まだ読み）。
- 読み手が外の道具（GiNZA）に頼っている。減らしたい。

## 2. 試しの作りで直す所

- 切れ目の信号を、しきい値を教えずに使う形（今は前半の本物の切れ目でしきい値を選んでいる）。

- 薄める事に意味を持たせる読み方: 今は割合で読むので、一様に薄めても何も変わらない。
