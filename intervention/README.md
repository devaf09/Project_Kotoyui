# 介入の研究（Project_Kotoyui の中の小さな企画）

2026-11-04 に始めた。本体の kotoyui.py（0.4.0）は止めて手直しだけにし、ここで新しい仕組みを試す。

## 目標

- 少ない例から多くを学ぶ。トランスフォーマーに代わる解析・生成の仕組みを目指す。
- 「介入」で関係を学ぶ（持ち主の案、Sin-CNN3 の学び 51・62 が元）:
  1. **語板**: 1 語（1 つの意味）= 1 枚の光の器。出口の明るさ = 属性（色・形・味…）の割合。対応のない属性には光が届かない（拡散）。
  2. **自覚**: 光の重なり・偏りから「既存と違う」「不自然」を感じ取る。
  3. **分ける**: 「既存と違う」の自覚から、同じ文字列でも新しい語板を作る（果物のリンゴ／人のリンゴ、緑で渋いトマト）。属性が多くなりすぎた語板や、2 つの関係を持つ語板も分ける。
  4. **介入**: 「赤いリンゴを緑に塗ったら渋くなる？」のような問いに、自覚で不自然な関係（色 → 味）を否定し、残りの属性を比べて「未熟 → 渋い」を見つける。
- 最初の成長段階は、きっかけを手で教える（持ち主 2026-11-04）: 語と属性の対応、動詞が変える観点（塗る = 色）、分けるしきい値。
  しきい値は、いずれ何かに合わせて変わる形か、光の属性の総量などから自動で決まる形にする。

## 物差し

本体で 10 択に寄りすぎた反省から、ここでは「見たことのない問いに答えられるか」を測る。

| 物差し | 何を測るか |
|---|---|
| 分かれ方 | 語ごとの語板の数が正しいか、語板の中身が 1 つの意味にそろっているか（純度） |
| 振り分け | 試しの文の語を、正しい意味の語板に入れられるか |
| 違和感 | おかしな文（その語のどの意味にもない属性）を、違いの大きさで見分けられるか（AUROC） |
| 介入の問い | 「塗ったら」「熟させたら」に、はい／いいえで正しく答えられるか。聞かれた語の組は使わない（1 語抜き） |
| 見たままの問い | 「緑のトマトは渋い？」 |
| 比べる相手 | 同じ文で学んだ GRU・小さなトランスフォーマー。問いと答えの例を足した場合も |
