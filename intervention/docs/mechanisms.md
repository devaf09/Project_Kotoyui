# 介入の研究: 仕組みの説明（I17〜I29）

この文書はコードの仕組みだけを説明する。結果の数・図・童話の文は非公開の置き場にあり、ここには書かない。
各実験の細かい設定は、それぞれのファイルの先頭の説明にある。

## 0. 全体の形

文を読むことも式を解くことも、同じ形で扱う。

1. **アレイ**: 入ってきたものを板の並びにする（数式なら数・演算・括弧の板、文なら文節の板）。
2. **文法解析グレイン（命令デコーダ）**: アレイの位置ごとに前後の板の種類を見て、「ここを縮める」か「待つ」かを出す。CPU の制御装置に近い役。
3. **縮める**: 選ばれた所の板を 1 枚にまとめ、**バッファ板**を作る。バッファ板は「値の帯」と「参照の帯（ネスト）」を持つ。
4. 1 枚になるまで繰り返す。最後の 1 枚（総合板 z）から、参照の帯をたどると元の並びに戻せる（展開）。
5. 答えが違ったときは **判断の板** が、どの一手で道が分かれたかを探して覚える。

```
アレイ:  [4] [7] [＋] [3] [5]
          │ まとめる       │ まとめる
         [47]  [＋]  [35]
              ╲  縮める ╱
               [82 | 参照: 47・＋・35]   ← バッファ板（値の帯 + 参照の帯）
```

## 1. 板と器

### 1.1 一般常識の数の板（I17、光の器）
- 0〜99 の数それぞれに 1 枚。出口の属性は 22 個（一の位 10・十の位 10・偶奇 2）。
- 数を説明する短い文（1 文に属性 1〜2 個）から、光の器（I1 の Devices、位相の板の重なり）を学ばせる。出口の明るさがその属性の割合になる。
- この研究の中で、学んだ重みが光の器そのものになっているのはこの板だけ（下の「デジタル重みの一覧」を参照）。

### 1.2 経験の器（I17 の Exp → I18 の ComboExp）
- 場面（記号の集まり、例: `操作:+1`・`一の位:8`）から結論（例: ずらし量、縮める / 待つ）を思い出す器。
- 結論ごとに口を 1 つ持ち、経験に出た記号の数え上げで、口ごとの起こりやすさ（記号ごとの割合の積、0.1 の平滑化）を比べる。
- I17 の器は記号 1 つずつしか持てず、「一の位が 8 で、+1」のような組み合わせを取りこぼした。I18 で、場面の面 s ⊗ s（2 枚の板を交差させて通した明るさの画素 = 記号の組）を持てるようにした。
  - **単独**: 記号 1 つずつ（面の対角）。
  - **組**: 記号の組（面の対角の外）。
  - **段々**: 記号 1 つ・2 つ・…すべての組。思い出すときは、経験に出たいちばん細かい組だけを使う。
  - **操作ごと**: 操作の記号ごとに器を分け、その中は記号 1 つずつ。
- 一度も経験に出ていない記号や組は、どの口も同じに照らす（光らない）。
- **例外の経験**: 場面の記号がすべてそろったときだけ光る注意の口。1 文しかない例外を、ふつうの経験に混ぜずに持つため。

### 1.3 差分（光の相関器、I17）
- 前と後の板の明るさを、観点ごとに巡回の相関で比べ、いちばん明るい「ずらし量」を読む。4f 系の相関器でずれを光の位置として読むのと同じ形。
- 答えるときは、前の板の明るさを観点ごとに巡回でずらす（位相の坂の板を通すのと同じ）。
- 引き算の**逆回し**: − は教えず、「答えの候補に +k すると今の数になるか」を足し算の経験に照らして選ぶ。

## 2. 算術（I19〜I23）

### 2.1 文法解析グレイン（I19）
- 窓（前後 2 つずつ）の板の種類（数・＋・−・×・（・）・端）の組を場面として、命令ごとに「縮める / 待つ」を経験の器で持つ。
- 命令の形と、命令を出せる位置（実行できる手）は手で与える。
- 動かし方は 2 通りある。**一括**はすべての位置を一度に照らして、いちばん明るい所を縮める。**走査**はカウンタを左から進め、縮めたら 2 つ戻る。
- 学び方も 2 通りある。**手順つき**は正しい順番を教える。**答えだけ**は短い式で縮め方を総当たりし、答えが合う道のある手を「縮める」にする。

### 2.2 判断の板（I20）
- 総当たりの代わりに使う。式を 1 つずつ解き、最後の答えだけが返ってくる。
- 答えが合ったら、通った道の一手ずつを「縮める」の経験に足す。
- 答えが違ったら、前から順に「この一手だけを別の実行できる手に替え、あとは今のデコーダのまま解き直す」を試す（介入）。
  答えが合った所が道の分かれ目なので、そこで選んだ手を「待つ」、替えた手を「縮める」として、注意つきで経験に足す。
- 2 手以上まちがえた式は見つけられないので見送る。

### 2.3 数の板が計算する: 演算の帯（I21）
- 1 桁の数の板ごとに、（役 = 左 / 右, 演算, 相手）→ 結果 の帯を持つ。文「3 に 4 を足すと 7」は、3 の板の（左, ＋, 4）と 4 の板の（右, ＋, 3）の両方に 7 を書く。
- 計算は、2 枚の板を同時に照らして帯の明るさを足し（融合）、いちばん明るい結果を読む。経験に無ければ「わからない」。
- **入れ替えの気付き**: 演算ごとに、同じ板の（左, op, y）と（右, op, y）の結果を比べる（差分）。一致の割合がしきい値（0.9）以上なら、その演算は左右を入れ替えてもよいと気付き、照らすときに入れ替えた組も使う。
- **逆回し**: a − b を「z + b = a になる z」として ＋ の帯から探す。
- **バッファ板** = 一般常識の板（1.1）の明るさ + 符号 + 参照の帯（左の板・演算・右の板）。値はバッファ板の明るさから読む。

### 2.4 桁上りの照射（I22）
- 0〜9 の板の演算の帯の出口を {一の位の数, 桁上り（＋・×）/ 桁下がり（−）} にする。
- 2 桁の計算を、条件分岐なしの 4 回の照射で行う。
  1. 一の位どうし → (一, c1)
  2. 十の位どうし → (t, c2)
  3. t と c1 を照らす → (十, c3)。「桁上りがあれば足す」ではなく、いつも桁上りの板（0 か 1）を足す。
  4. c2 と c3 → 百
- 手順 1〜4 は手で与えている（グレインに学ばせるのは次の段）。

### 2.5 数字が続いたら桁を判断する（I23）
- 式を数字 1 文字ずつの「字の板」で渡す。命令は 4 つ: 縮める・外す・**まとめる**（字 字 → 2 桁の数の板）・**読む**（字 → 1 桁の数の板）。
- 字の所ではまとめるも読むも出せる。どちらを出すかを、命令ごとの器（操作ごと）で、答えだけから判断の板で学ぶ。
- **断られたら覚える**: 実行できない手を選んだら、その手を「待つ」として覚える（実行できる手を手で教えない形）。

### 2.6 板の操作を光で指定する: つなぎの板（I28）
- I22 の手順 ①〜④（どの出口を次のどの入口へ送るか・どの演算で照らすか・答えの各桁をどの出口から読むか）を、**つなぎの板**（光のクロスバー）に置き換える。
  - 口: 入口の数の板 A一・A十・B一・B十 と、照射 6 つの出口（一の位・桁上り）。どれも 0〜9 の板の光。
  - 行: 照射ごとの「左の入口・右の入口・演算」と、答えの「百・十・一」。列: 口か演算。行ごとにいちばん明るい画素だけを通すマスク（勝者総取り）。
  - 照らす: マスク × 口の光（one-hot）の行列の掛け算で入口へ光を送る。照射の番号は順番ではなく、入口が光った照射から照らす（輪になるつなぎは答えが出ない）。
  - 式の演算の光が、つなぎの板の層を選ぶ（演算ごとに 1 層）。
- 学び（答えだけ、判断の板）: 違ったら、答えと桁ごとの差分を取り、違った桁の答えの行と使っている照射の行だけを替える候補にする。
  1. 画素 1 つ → 2 つを替えて、いまの例が合い、覚えの例（新しいものから 40 個）も壊れない替え方を探す。
  2. それで直らなければ、**照射 1 つをまるごと決め直し**（入口 2 つ + 演算）、違った桁の答えの行をその出口へつなぐ。空いている照射から試し、だめなら使っている照射を 1 つ組み直す。
  3. 見つかれば、替えた画素をその行のいちばん明るい画素より明るくする。
- 空いている照射は、新しい手順（桁上りを次の桁へ足す、など）を足す場所になる。仮の語板の「共有属性の空き」と同じ考え方。
- **忘れて整理する**（I28b、--sleep K）: 見送りが K 回続いたら、つなぎの板を空に戻し、覚えの例と見送った例を易しい順（2 桁の数の数、答えの桁数）に並べて学び直す。

### 2.7 間違った記憶を直す（I29）
- 演算の帯に誤った文（例えば「7 に 5 を足すと 3」）が入っているとき、式の答えとの食い違いから直す。
- 答えが違ったら、その式で照らした帯の組（照射ごとの (a, 演算, b)）を 1 つずつ取り、結果だけを別の値に替えて解き直す（介入）。答えが合う替え方を直す候補にする。
- 候補が k 個なら、それぞれに 1 / k 票を入れる。同じ組・同じ値に票がたまり、その組でいちばん多ければ、その文をいまの明るさより強く書き直す。1 つの式では決めつけない。
- 入れ替えた組（b, 演算, a）が同じ結果を言っている候補には、票を足せる（＋ と ×）。
- 照らすときは入れ替えの気付きを使わない（誤った a op b と正しい b op a が同じ明るさになるため）。

## 3. 文の圧縮と展開（I24〜I27b）

### 3.1 下ごしらえ（I24）
- 童話のファイルを読み、文に切る（「」の中では切らない）。GiNZA で語・品詞・係り受けを付ける。
- 語板の被覆（内容語のうち語板がある割合）を数え、知らない語を話ごとに並べる。
- 曖昧な例文の、修飾する語・意図の係り先・誤読の係り先は手で付ける（非公開の置き場）。
- 素の基準は 2 つ。GiNZA の係り受けを上にたどって先に着いた方と、**近い方に係る**。

### 3.2 1 文を 1 枚に縮める（I25）
- アレイ = 文節の並び（ginza.bunsetu_spans）。文節の種類 = 中心の語の品詞 / 最後の助詞か係り方（連体・連用・文末）。
- 命令は 1 つで、「i の文節を右隣に係らせて 1 枚にする」。日本語は後ろに係るので、**縮める順番が係り先を決める**。
- GiNZA の係り受けを正しい順番として、窓（前後 2）の種類の組で縮める / 待つ を学ぶ（器は組）。
- バッファ板: 値 = 語板の明るさの和、参照 = 係った文節。
- **仮の語板**（持ち主の案）: 語板に無い語は空の板を作り、読み進めるほど育てる。新しい名札は足さず、今ある名札（共有属性の空き）だけを明るくする。
  - 形容詞 A に修飾されたら: 帯 B に「性質:A」を足し、A の「修飾先:クラス」を帯 D のクラスへ。
  - 動詞 V に連体修飾されたら、または V の が になったら: 帯 C に「V/する」を足し、V の「主語:クラス」を帯 D へ。
  - V の を になったら: 帯 C に「V/される」を足し、V の「目的語:クラス」を帯 D へ。

### 3.3 曖昧な係り先を判断の板で見直す（I26）
- 基本は近い方に係る。手がかりが遠い方を強く推すときだけ、その一手を遠い方に替える。
- 手がかり (a) は一般常識の語板で、修飾する語と係り先の語の合い方（compat）を見る。
  - 動詞 → 名詞: 名詞の帯 C の「V/する・される・に・で・を」と、名詞のクラス × 動詞の「主語:・目的語:クラス」の重なり。
  - 形容詞 → 名詞: 名詞の帯 B の「性質:A」と、名詞のクラス × 形容詞の「修飾先:・主語:クラス」の重なり。
  - 名詞の → 名詞: 帯 E（部分・材料など）とクラスの重なりを、両方の向きで見る。
  - 候補が動詞（連用の係り）のときは、まだ測る手が無いので 0 にする。
- 手がかり (b) は話の文脈で、修飾する語から係り受けを 2 歩までたどって候補の語に着いた回数。
- 語板の引き方は、そのまま → 複合語の後ろの部分 → 話の文から作る（その語が出る文の語板の和）の順。

### 3.4 圧縮と展開を比べる（I27a）
- 話（4 段の長さの文すべて、または一部の段）を、語ごとの「話の板」に縮める。
  - 名詞の板には、修飾した語・が / は になった述語・を になった述語・の で修飾した名詞を数えて入れる。
  - 動詞の板には、連用で係った語を入れる。
- 曖昧な例文を両方の読みで展開し、「修飾する語 M が候補の語に付く」という属性が話の板にすでにある方（食い違わない方）を選ぶ。どちらにも無ければ近い方のまま。
- I26 の文脈は M → N の向きだけを見ていた。ここでは「竹が光る」のような逆の向き（N が主語）も、光る が 竹 に付く属性として数える。
- どの長さの段で話の板を作るかを比べられる（短い段ほど、縮めたこと自体で曖昧さが生まれることがある）。

### 3.5 迷ったときだけ聞き返す（I27b）
- 基本の読み = 近い方 + 話の板（I27a）。
- 話の板で決まらなかった例文について、**迷いの強さ** = 遠い方の合い方 − 近い方の合い方（I26 の compat）。連用の例文は迷いを低くする。
- 迷いの強い順に k 個だけ聞き、聞いた例文は返ってきた答えに従う。実験では、手で付けた係り先を「聞けば返ってくる答え」の代わりにした。
- 比べる相手は、でたらめな順に聞く場合と、誤りだけを知っている理想の順。
