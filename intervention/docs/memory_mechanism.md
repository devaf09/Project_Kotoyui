## ひとことで

光に覚えるものは 3 つ。**語板**（語の意味）、**親の語板**（親子。語板の明るさの和で、別に学ばない）、**経験の器**（判断の記憶）。
その外側に、手で与えるデジタルの表（語と属性の対応、動詞の観点、しきい値、「X の Y」の規則）がある。

## 記憶 1 語板（語の意味の記憶）

- 1 つの意味 = 1 台の光の器（位相の板 8 枚 + 回折 + レンズ、`i02_reverse.PortDevice`）。学ぶのは板の位相だけ。
- 出口の明るさ = その意味の属性の割合（リンゴ/果物 なら 種類:果物・味:甘い・色:赤 が明るい）。対応のない属性には光が届かない。
- 入口に「口」（周波数の違う波）を複数持てる。1 語の中の別の物・別の状態を、口ごとに持つ。
- **書く**: 文を読むたびに板を学び直す。I1 では「既存の語板と違う」が 0.5 以上なら同じ文字列で新しい語板を作った。
  I3 以降は、口 2 つで学んで競合する観点が 2 つ以上（など）なら分ける（逆からの判断）。
- **読む**: 順に通す → 属性の明るさ（「緑のトマトは渋い？」）。逆から入れる → どの口に戻るか（分けるかの自覚）。違いの大きさ → 違和感。

## 記憶 2 親の語板（親子の記憶、I10）

- 親 = 子の語板の明るさの和（光の融合）。親の器は別に学ばない。祖先（果物全体）は全部の科の和。
- **書く**: 子の語板が育てば、和も自動で変わる。親子の向きは「X の Y」の手の規則で決める。
- **読む**: 知らない子（新しい品種）の属性を、親の明るさから確率で想定する。≥0.7 きっと、0.4〜0.7 たぶん、<0.4 わからない。
- 住所（日本 → 宮崎 → 日南）は、深さごとに 0.5 倍で受け継ぐ形を表で確かめただけ（数字の実験はまだ）。

## 記憶 3 経験の器（判断の記憶、I7〜I9）

- 光の器 1 台。口 = 結論の種類（本物・例外あり・見かけ・不明・分ける・分けない）。
- 経験 1 つ = 記号の組。例: {観点:色, 支持:多い, 反例:多い, 共に変わる:あり, 相手の反例:なし, 割合:中, 結論:見かけ}。
- **書く**: 世界 A で判断（色は味の原因か、この語板を分けるか）するたびに 1 つ足す（1 seed で約 375 個）。
  結論を付けるのは、規則（I7・I8）か、答えの採点（I9: 27 通りを試していちばん合ったもの）。
  集め終わってからまとめて学ぶ。口ごとにその種類の経験だけを学ばせる（I8b の labeled。口を隠して学ぶと混ざった）。
- **読む**: いまの場面を記号にして 1 回通す。口ごとの起こりやすさで明るさを重ね、いちばん明るい結論を選ぶ（本物 → 効き目 1、例外あり → 支持の割合、見かけ → 0）。

## 時間の流れ

1. 世界 A の文を読み、語板を学ぶ・分ける。
2. 世界 A で判断し、経験を集めて、経験の器を学ぶ（ここで固定）。
3. 世界 B の文を読み、語板を新しく学ぶ（世界 A の語板は使わない）。
4. 世界 B の判断を、経験の器に 1 回通して決め、問いに答える。持ち越すのは経験の器だけ。

## いまの限界（次の実験の候補）

- 経験の器は世界 A の後にまとめて学び、その後は増えない。持ち主の「失敗や反映で増える」はまだ（口を足して育てる形は未実装）。
- 結論は 1 つだけ選ぶ。結論の分布・確率で持つのは I11 の予定。
- 語板は増えるだけで、まとめ直し・忘れることはない。世界 A と B の語板は別々で、同じ語が出ても引き継がない。
- 口の割り当て（結論の種類 = 口）と、場面の記号への丸めはデジタル。
- 親の語板は和を取るだけなので、知っている子が少ないと言い切りすぎる（I10 で「きっと」の正解率 0.63）。
