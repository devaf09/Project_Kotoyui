# 介入の研究: デジタルの重み・手で決めた部分の一覧（I17〜I27b）

持ち主の構想（2026-11-06）は「最初はデジタルの重みで良い」。いま何が光の器で、何がデジタル（数え上げ・表・手のきまり）なのかを、ここに一覧にする。
光の器に置き換えるときの手がかりも、分かる範囲で書いた。結果の数はここには書かない。

## 見方

- **光**: 学んだ重みが光の器（位相の板の重なり、I1 の Devices）になっているもの。
- **数え上げ**: 経験の回数を Counter や表で持ち、明るさの代わりにしているもの。形は光の器と同じ（口ごとの明るさ）だが、光で通していない。
- **手のきまり**: コードに書いた手順・しきい値・式。学んでいない。
- **外の道具**: GiNZA など、外から借りたもの。

## 1. 光になっているもの

## 2. 算術（I17〜I23）のデジタル部分

## 4. まとめ

- 光になっているのは、一般常識の数の板だけ。
- いちばん多いのは**数え上げの経験の器**（ComboExp）。算術の命令デコーダも、演算の帯も、文節のグレインも、この形で持っている。ここを光の器にできれば、多くの部分が一度に置き換わる。
- 光の形がいちばん近いのは、差分の相関器（4f 系）と、全位置を一度に照らす「一括」の動かし方。
- 手のきまりとして残っていて、学ばせたいものは 3 つあった。桁上りの照射の手順（①〜④）は I28 でつなぎの板に置き換えた。残りは、仮の語板の育て方（どの係り方がどの帯を変えるか）と合い方の式。
- 判断の板の手順（一手ずつ替えて解き直す）は、制御の側に残る見込み。
