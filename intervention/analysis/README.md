# intervention/analysis/ — 会話の試しの記録を数える道具

会話の試し（chat_partner.py と chat_bot3.py）の記録を読んで、数を出す小さなプログラムです。
記録そのもの（会話のログ・記憶板）は公開していないので、ここにあるのは数え方だけです。

記録の置き場は、環境変数 `KOTOYUI_PRIVATE` で指定します（無ければ、リポジトリの隣の `Project_Kotoyui_private/`）。
その下の `i35y/`（会話のログと 1 往復ごとの状態）と `memory/`（記憶板）を読みます。リポジトリの直下から実行します。

| プログラム | 何を数えるか |
|---|---|
| `i35y_precheck.py` | 回す前の確かめ。話し相手と先生のローカル AI が返事を返すか |
| `i35y_unanswered.py` | ボット自身についての問いのうち、答えられなかったものを話題ごとに数える |
| `i46_count.py` | I46 の回ごとの数（返事の種類など） |
| `cmp3.py`・`sb_count.py` | 回どうしの比べ（答えられた割合、自分の板が使われた数） |
| `imp_count.py`・`mem_count.py`・`mem_cmp.py` | 大事な板・記憶板に入った数と、思い出しの当たり |
| `p_count.py`・`rev_trace.py`・`know_scan.py` | 返事の作り方ごとの数、作り直しの跡、「知ってる？」への答え |
| `replay_cmp.py`・`script_cmp.py` | 記憶板を作り直して比べる、決まった問いの台本で比べる |

その場で書いた道具なので、回の名前（i37f・i40a など）がプログラムの中に書いてあります。自分の記録に使うときは、そこを書き換えてください。
